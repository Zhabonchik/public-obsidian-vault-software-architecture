> **Core Constraint:** Imposes discipline over **direct transfer of control** (eliminates `goto`).
    
- **Key Concept:** Any program can be constructed using only three basic control structures:
    
    - **Sequence:** Step-by-step execution.
        
    - **Selection:** Conditional execution (`if/then/else`).
        
    - **Iteration:** Repeated execution (`do/while/for`).
        
- **Architectural Value:**
    
    - Allows code to be decomposed into small, provable, and testable units.
        
    - Enables modern automated testing by guaranteeing that modules can be tested independently.
